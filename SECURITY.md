# Security Policy

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.
Report it privately through [GitHub's private vulnerability reporting](https://github.com/chathurabuddi/mouse-scroll-cue/security/advisories/new) instead.

Include what you found, how to reproduce it, and what impact you think it has.
You can expect a first reply within a week.

## Scope

The package is a static SVG file with a small CSS animation and no JavaScript.
Relevant reports include anything that makes the SVG run script, load outside resources, or misbehave when inlined into a page.
Issues in the demo page and in the release workflows are in scope too.
